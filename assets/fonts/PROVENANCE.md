# Browser symbol fallback

NotoSansSymbols2-Regular.ttf, unmodified, from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/notosanssymbols2

Downloaded 12 September 2026 from the repository's raw main branch. Licensed under SIL Open Font License 1.1; accompanying OFL-NotoSansSymbols2.txt is retained. Used only as a Web fallback for symbols absent from the browser's system-font fallback (charge pips, mastery diamond). Native typography remains unchanged. This is a font resource, not generated artwork.
